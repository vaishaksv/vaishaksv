## 🔥 Featured Project

### [Selenium The Internet Framework](https://github.com/vaishaksv/selenium-the-internet-framework)
A production-ready automation framework for the-internet.herokuapp.com with enterprise-grade features.

**Key Highlights:**
- ✅ **Page Object Model** - Clean, maintainable architecture
- ✅ **Auto-Retry Mechanism** - Reduces flaky test failures
- ✅ **Data-Driven Testing** - TestNG DataProviders with multiple sources
- ✅ **Allure Reporting** - Beautiful HTML reports with screenshots
- ✅ **Parallel Execution** - Thread-safe with ThreadLocal
- ✅ **Multi-Environment** - Dev/Test/Staging/Prod support
- ✅ **Cross-Browser** - Chrome, Firefox, Edge, Safari
- ✅ **CI/CD Ready** - Headless mode and Maven integration

**Tech Stack:** Java 11+ | Selenium 4.15 | TestNG 7.8 | Maven | Allure
